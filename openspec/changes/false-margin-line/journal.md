### G2 · Диагноз первой ступени

Продукт — `/tmp/false-margin-line/diagnosis.md` (числа 2.1–2.4), инструментованный бандл `/tmp/false-margin-line/diag/` (плагин esbuild подменяет `detectRuling.ts` копией с хуком только на чтение, `src/` не менялся). Все числа аудитора спеки воспроизведены.

При сдвиге границы трети на +0,5 шага фантома нет, при −1 шаге фантом переезжает на 1565 (2,16 барьера) — правка окна не лечит. Та же картина на `IMG_1812`: правый кандидат 1656,5 — 0,93 барьера на кадре, 1,95 на копии (не срабатывает только из-за стороны `left`, заданной копии).

Условие применимости (запас не меньше 0,1 до барьера) выполнено:

Наименьший запас — `grid/2`, 2,23 барьера.

### Решение координатора: цвет как вето

Диагност (/tmp/false-margin-line/diag-g4/) на 34 снимках, оба прохода: фаза не различает (настоящие 0,06…0,31 против фантомов 0,01…0,40; IMG_1705 — линейка, вертикалей нет), край вырезки, выход линий и яркостная глубина тоже перекрываются. Краснота вдоль трассы кандидата (избыток R−G над скользящей медианой, медиана по узлам) разделяет: вторая ступень — настоящие ≥ 26,5, ложные ≤ 6,1 (51/495 кандидатов); первая — ≥ 33,4 против ≤ 5,4. Любой порог 7…26 даёт один итог.
Выбрано (б1): цвет — вето по кандидатам яркостной меры обеих ступеней, не самостоятельный поиск. Итог симуляции: IMG_1705 → нет, IMG_1808 → 2306,5 right (0,02 шага от черты 2305, пропуск закрыт), остальные 32 без изменений, profiles.json не меняется.
Отвергнуто: (а) фаза — перекрытие; (б2) поиск по профилю красноты — сдвигает x подтверждённых линий (IMG_1812 447 против 473,9, пресеты 0,3…1,6 px) и охват IMG_1812 0,27 у границы 0,2.
Серый снимок: вето выключается, если P99 |R−G| по кадру < 5 (цветные 17…59, серый скан 0…1) — поведение как у яркостного пути. Канал необязательный в SheetImageData, Int16 (24 МБ на 12 Мп), нет канала — вето молчит.
Эскалация design («расширение SheetImageData — вопрос пользователю») решена координатором: пользователь недоступен, делегировал решения, приоритет — надёжность распознавания, несколько секунд допустимы. Цена времени — до +1,6 с на снимок (+35 %), в порог +3 с укладывается; рост больше 20 % — числом в тело PR; удешевление (полосы только в крайних третях и только при кандидате выше барьера) — задачей.
Спека обновляется (design решение 2, спека требований, tasks) до продолжения G4.
