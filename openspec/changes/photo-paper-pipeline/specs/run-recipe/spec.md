## Purpose

Собирает всю случайность генератора в один воспроизводимый рецепт: одно число определяет, какие листы, чернила, почерк и оптика достанутся каждой странице прогона, чтобы результат можно было повторить, а тесты — закрепить.

## ADDED Requirements

### Requirement: Рецепт прогона выводится из одного числа

Все случайные параметры прогона SHALL выводиться из единственного числа — seed прогона. Отрисовка SHALL не использовать иных источников случайности.

#### Scenario: Повторяемость прогона

- **WHEN** прогон запускается дважды с одним и тем же seed, текстом и семьёй листов
- **THEN** обе выдачи совпадают попиксельно

#### Scenario: Новый прогон меняет всё сочетание

- **WHEN** пользователь запускает новый прогон
- **THEN** меняются и выбранные экземпляры листов, и цвет чернил, и параметры почерка, а не только рисунок искажений

### Requirement: Рецепт покрывает бумагу, чернила, почерк и оптику

Рецепт прогона SHALL определять: экземпляр листа для каждой страницы, цвет чернил, параметры неровности почерка, параметры вариативности контуров и параметры оптики страницы.

#### Scenario: Состав рецепта

- **WHEN** сформирован рецепт прогона
- **THEN** в нём есть выбранный экземпляр листа на каждую страницу, цвет чернил, параметры почерка и параметры оптики

#### Scenario: Семья листов задаётся пользователем

- **WHEN** пользователь выбрал семью листов
- **THEN** рецепт выбирает экземпляры только внутри этой семьи и не подменяет саму семью

### Requirement: Цвет чернил берётся из палитры правдоподобных

Случайно выбираемый цвет чернил SHALL браться из набора цветов реальных пишущих средств с небольшим разбросом, а не из всего цветового пространства.

#### Scenario: Правдоподобный цвет

- **WHEN** рецепт выбирает цвет чернил случайно
- **THEN** выбранный цвет принадлежит набору цветов реальных ручек с отклонением в пределах допустимого разброса

#### Scenario: Пользователь фиксирует цвет

- **WHEN** пользователь задал цвет чернил вручную
- **THEN** рецепт не меняет его при новом прогоне

### Requirement: Соседние страницы не получают один экземпляр листа

Рецепт SHALL не назначать один и тот же экземпляр листа двум подряд идущим страницам, пока в семье есть более одного экземпляра.

#### Scenario: Разные листы подряд

- **WHEN** генерируется пачка страниц по семье, содержащей не менее двух экземпляров
- **THEN** ни одна пара соседних страниц не использует один и тот же экземпляр

#### Scenario: Семья из одного экземпляра

- **WHEN** в семье остался единственный экземпляр
- **THEN** он используется на всех страницах, ошибки не возникает

### Requirement: Изменение текста не сбрасывает рецепт

Правка текста SHALL сохранять текущий рецепт прогона. Смена рецепта SHALL происходить только по явному действию пользователя.

#### Scenario: Правка текста

- **WHEN** пользователь дописывает предложение к тексту
- **THEN** выбранные листы, цвет чернил и параметры почерка остаются прежними

#### Scenario: Явная перегенерация

- **WHEN** пользователь запускает новый прогон
- **THEN** рецепт формируется заново
