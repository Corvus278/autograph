# План прогона: margin-line-trace

База прогона: `b26e45c`
Гейт: `npm run lint && npm test`
Быстрые проверки: `npm run typecheck`, `npx vitest run --project=unit tests/<файл>`
Долгие слои: `npm run measure:sheet` — G1, G3, G5, G6, G7, G8; `npm run build:paper` — G5; `npm run test:stories` — G7
Хук коммита гоняет полный `tsc` и `vitest --changed`: каждая группа оставляет типы и юнит-тесты зелёными.
Пути `lib/paper/` — от `src/pages/Generator/`. Замеры — вне репозитория, в `/tmp/margin-line-trace/`.
Требования: у change одно — `paper-profile` → «Линия поля находится, когда в кадре она не вертикаль»; ниже — сценарии.

## Контракты

- **K1 Полосовая ступень** — вторая ступень в `detectRuling.ts` отдаёт кандидата того же вида, что `findMarginLine`
  (`{x, side}`), и уходит в тот же `refineMarginLine`. Зовётся только при `findMarginLine(...) === null` и
  `options.marginLineSide !== null`; сторона из опций ограничивает её отбор. Глубина кандидата — медиана по полосам,
  где трасса его нашла. Владелец G3; потребители G4, G5.
- **K2 Отчёт линии поля** — `DetectedRuling` и `SheetPhotoDiagnostics` получают отчёт: ступень (`профиль`/`полосы`/нет),
  доля полос с узлом, отношение «глубина / дециль соседей», имя связавшего порога (`соседи`/`сигма`/`минимум`).
  В `SheetRuling` полей не прибавляется. Печатает `describeSheetReport`. Владелец G4; потребители G5—G8.
- **K3 Барьер одной меры** — обе стороны сравнения меряются одним полосовым способом. Множитель — нынешний
  `MARGIN_LINE_DEPTH_RATIO = 1.5`; своя константа заводится только выводом замера 3.4 по правилу разделения с запасом
  0,1. Владелец G3; правит только G5.
- **K4 Синтетика** — `SyntheticSheetParams` получает снос линии поля по `x` (доля шага сверху вниз, поверх
  `marginLineBend`) и листы «без линии поля» и «глубокая вертикаль на фазе гребёнки». При нулевом сносе растр бит-в-бит
  прежний; после G2 хелпер не правится. Владелец G2; потребители G3, G5.
- **K5 Числа до правок** — `/tmp/margin-line-trace/`: `baseline.md` (18 видимых + 8 пресетов), `ground-truth.md`
  (`IMG_1806`, `IMG_1807`), `calibration.md` (таблица 3.4); `holdout.md` не открывает никто до G8. Владелец G1;
  потребители G3, G5—G8.
- **K6 Пресет-пак бит-в-бит** — `md5 -q public/paper/profiles.json` = `bbb9e9b963bc092e50aad90f60fd39ce` после
  `npm run build:paper`, ступень у восьми — `профиль`. Артефакт правит только G5. Владелец G3; все.
