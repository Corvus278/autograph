# Журнал прогона

Решения без заказчика, отступления от спеки, итоги аудитов и долг прогона change `sheet-native-ruling`.

## 2026-09-12

### Старт прогона

База прогона: 4bbf8a1136d9483ae93db517c8b58de79f1e9dcd. Масштаб средний (30 задач), режим «дерево», группы последовательно.
Гейт: `npm run lint && npm test`; G8 дополнительно `npm run test:visual` (docker есть).
6.5 вне групп: живая приёмка в браузере со сверкой снимков с фотографией — агент выполнить не может, остаётся [ ] до пользователя.
Решение координатора (K3): спека молчит, должна ли раскладка чётных страниц брать отражённую разлиновку. Выбрано: одна отражённая разлиновка на раскладку и отрисовку. Альтернатива — отражать только при отрисовке. Отвергнута: на наклонном листе вместимость страницы разошлась бы с отрисовкой, приоритет надёжности.
Решение координатора: pre-commit гоняет полный typecheck, поэтому каждая группа оставляет tsc зелёным. План возвращён планировщику: временная совместимость в G1, её удаление — в G8 вместе с 1.4. Альтернатива — красный tsc до G8 — несовместима с коммитом на группу.

### G2 · Калибровка страницы

Решения: deriveGeometry(SheetCalibration, metrics, correction); старая сигнатура — deriveCanonGeometry @deprecated (K10). Линия поля сужает блок, но не выводит за поле (зазор ≥ step/5). Слайдеры в долях шага: кегль/интервал ±0.25, сдвиги ±2, ширина ±4, запас 0..20.
Отступления: новые селекторы продукт пока не вызывает — подключают G4/G6. Удалён тест «не перекладывает текст при смене экземпляра»: противоречит сценарию «Смена экземпляра пересчитывает геометрию» (буква спеки). На клетке при нечётном запасе или поправке интервала число строк зависит от дробной части — следствие K7.
