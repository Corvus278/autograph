## Контракты

- **K1 Засев схождения** — `measureBandedPeriod(image, options)` → `{ step, phase, skewAngle, convergence, bandSteps }`,
  px входа; `step = 0` — отказ. `convergence` — `k` из `step(u) = step₀·(1 + k·u)`, `u` — координата вдоль линий от
  середины области с линиями, 1/px. Перевод в `RulingPerspective.convergenceY` — в `detectRulingPerspective`: шаг по `y`
  в его модели растёт как `(1 + q_y·Δy)²`, отсюда `q_y ≈ k/2`. Владелец G3; потребители G4, G6.
- **K2 Полосовая ступень** — `DetectedRuling` получает `bandSteps: number[]` и `convergenceSeed: number`; пусто и `0` —
  глобальный профиль взял порог, полосы не считались. `detectRuling` зовёт их только при
  `period.confidence < confidenceThreshold`. Поля — в `DetectedRuling`, не в `SheetRuling`/`SheetRulingSource`: формат
  хранения не меняется. Владелец G4; потребитель G6.
- **K3 Диагностика** — `SheetPhotoDiagnostics.banded: { steps: number[]; drift: number } | null`, `null` — полосы не
  понадобились; печатает `describeSheetReport`. Владелец G6; потребитель G7.
- **K4 Синтетика** — `SyntheticSheetParams` получает долю дрейфа шага по высоте и долю схождения по ширине; прежние
  вызовы не меняются, при нулевых долях растр совпадает с базой до бита; после G2 хелпер не правится. Владелец G2;
  потребители G3, G4, G5, G6.
- **K5 Числа до правок** — `/tmp/perspective-ruling-detection/baseline.md` (10 отказных, 8 пресетов, время); удержанная
  выборка — `holdout.md` там же, его не открывает никто до G8. Владелец G1; потребители G4, G7, G8.
- **K6 Пресет-пак бит-в-бит** — `public/paper/profiles.json` после `npm run build:paper` не меняется; правит и коммитит
  его только G7. Изменившийся артефакт — возврат правки, а не новые числа. Владелец G4; все.
