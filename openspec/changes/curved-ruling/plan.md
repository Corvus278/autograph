# План прогона: curved-ruling

База прогона: `74f8a3489ce5eadf84d58eac2ed261956fceda3b`
Гейт: `npm run lint && npm test`
Быстрые проверки: `npm run typecheck`, `npx vitest run --project=unit tests/<файл>`
Долгие слои: `npm run build:paper` — G3, G7; `npm run test:stories` — G9, G10; `npm run test:visual` — G10
Хук коммита гоняет полный `tsc` и `vitest --changed`: каждая группа оставляет типы и юнит-тесты зелёными.
Пути `lib/`, `model/`, `ui/` — от `src/pages/Generator/`.

## Контракты

- **K1 RulingBend** — px кадра; `offsets` плоский, индекс `r·columnCount + i`, кратны 0,01; строки по `u = y − x·tgθ`. Владелец G1; все.
- **K2 Выборка** — `sampleRulingBend(bend, skewAngle°, x, y)` и `sampleRulingBendSlope` (∂d/∂x при const u) из `lib/paper`.
  Владелец G1; потребители G4, G5, G8, G9.
- **K3 Линия** — `y_k(x) = firstLinePhase + k·step + x·tgθ + d(x, u_k)`, `d > 0` — вниз. Владелец G1; потребители G4, G5, G8, G9.
- **K4 Обязательный bend** — поле в `SheetRuling`/`RulingDetection` (G1) и `RenderGeometry` (G5) вводится со всеми литералами.
- **K5 Отражение** — изгиб отражает только `mirrorSheetRuling`; `buildPageRenderParams` берёт готовый `bend` разлиновки страницы.
  Владелец G1; потребитель G5.
- **K6 Синтетика** — API `tests/helpers/synthetic-sheet.ts`, эталон — аналитическое `d(x, y)`, не `RulingBend`; прежние вызовы
  не меняются; в волне 2 хелпер не правится, недостающее рисуется в своём тесте. Владелец G2; потребители G3, G4, G7.
- **K7 Измерение** — `detectRulingBend(image, ruling, { left, right })` → `{ bend, foundNodeShare }`, доля есть и при `null`.
  Владелец G4; потребитель G7.
- **K8 Режим изгиба** — код изгиба в отрисовке только при `geometry.bend !== null`; угол выборки — `blockRotate`; точки — px
  страницы без `scale`; лента ровного листа прежняя. Владелец G5; потребители G8, G9.
- **K9 Раскладка** — `lib/calibrate`, `lib/paginate`, `model/measureLayout.ts` не читают `bend`. Все; проверяет G8 (4.5).
- **K10 JSON** — `bend` в `profiles.json` и записи своего листа необязателен, испорченный → `null`, `PAPER_PROFILES_VERSION`
  остаётся 2. Владелец G6; потребитель G7.
- **K11 Журнал** — 2.10 повторяет замер 2.1 той же командой и синтетикой, записанными в журнал; 3.4 сверяет поля с эталоном 2.6.
  Владельцы G2, G3; потребитель G7.
- **K12 Красная зона** — с 3.4 до G9/G10 `test:stories` и `test:visual` на пресетах могут падать; G7 их не гоняет.
  Вводит G7; снимают G9, G10.
