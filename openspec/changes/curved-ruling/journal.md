### G4 · Измерение изгиба

Решения: вход `Pick<SheetRuling, step|firstLinePhase|skewAngle|margins>`, строки узлов — линии между полями (допуск ⅓ шага, 0 = линии до края); типы RulingBendRegion/RulingBendDetection/BendBaseRuling в detectRulingBend.ts; выброс заменяется медианой по столбцу, по строке заполняются только ненайденные узлы (заполнение заменённых срезало бы гребень); columnOrigin = cropLeft − 0,5 + spacing/2; область < 8 px или step ≤ 0 → `{ bend: null, foundNodeShare: 0 }` (закрывает долг G1 про columnSpacing = 0). Сверх задачи — по тесту на каждое условие null.
Отступление: в наклонных тестах область 24…696, не весь кадр — синтетика обрезает нижние линии у края; настоящую область даст 2.9.
Риск для G9: прогиб 0,3 шага, сходящий к нулю у краёв области, в полуполосе за крайним узлом даёт 0,95 px при допуске 1,2 (K1: за узлом смещение константа); круче — ⅟₂₀ шага у края не гарантирована.
Аудит: ok с первого круга; мутации M1 (без проверки скачка) и M2 (без порога ½ шага) ловятся, M3 (без замены выброса медианой) — нет.
Долг: detectRulingBend.ts:349 замена выброса без теста (одиночный выброс внутри строки и у крайней строки); :558 `flat().map()` против code-style #15; нет jsdoc у EMPTY_DETECTION/computeQuantile/roundOffset (:179/241/437); tests/paper-detect-bend.test.ts:255 повторяет формулу реализации; дублирование трассировки с G3 (принято).
