## 2026-09-20

### Старт прогона

База прогона: ee2314db413e7083c1672b25c920dc2ead610050. Масштаб средний, 6 групп, 5 волн, режим «дерево».
Гейт: `npm run lint && npm test`. Долгие слои (test:stories, test:visual) — после G5.

Задачи вне плана, агент выполнить не может (нужен живой браузер, DevTools-офлайн, установка в ОС):
6.1 приёмка оффлайна на preview, 6.2 установка приложения, 6.3 цикл обновления с подменой раздачи.
Остаются `[ ]`. Частично страхуются тестами G3 (полнота precache, базовый путь) и G5 (плашка на живом App).

Решение координатора (спека молчит): `tests/pwa-precache.test.ts` выносится в отдельный проект vitest
(`pwa`) с командой `npm run test:pwa` и включается в гейт вместе с `npm test`. Альтернатива — оставить его
в проекте `unit` — делает хук коммита (`vitest --changed`) минутным из-за сборки `dist`. Путь и содержание
теста из задачи 3.1 не меняются.

### G1 · Иконки приложения

G1 закрыта, аудит ok с первого круга.

Решения: фон maskable берётся из `fill` первого `<rect>` в favicon.svg, жёсткая константа — только фолбэк;
в svg перед растеризацией подставляются `width`/`height`, иначе Chromium рисует 300×150 по одному `viewBox`.
Усиление беззубой проверки «файл создан»: `tests/app-icons.test.ts` декодирует PNG и требует сплошной фон в
рамке ~10 % у maskable (зубы подтверждены мутациями SAFE_ZONE=1 и 0.9).

Отступление: задача 1.3 требует коммита PNG — в режиме «дерево» коммит делает координатор, этой записью.

Долг: scripts/build-app-icons.ts:156 — пустой dataURL молча пишет пустой PNG вместо падения;
tests/app-icons.test.ts:216 — у icon-192.png не проверен прозрачный угол.
