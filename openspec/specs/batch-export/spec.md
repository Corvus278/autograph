## Purpose

Делает основным сценарием выгрузку целой пачки страниц одним действием: текст любой длины превращается в набор изображений, каждое со своим листом и своим почерком, с понятным прогрессом и без исчерпания памяти.

## Requirements

### Requirement: Выгрузка всей пачки одним действием

Система SHALL позволять сгенерировать и выгрузить все страницы текущего текста одним действием. Результат SHALL быть одним архивом.

#### Scenario: Пачка выгружена архивом

- **WHEN** текст разложен на несколько страниц и пользователь запускает выгрузку пачки
- **THEN** скачивается один архив, содержащий по одному изображению на каждую страницу

#### Scenario: Порядок и имена файлов

- **WHEN** архив распакован
- **THEN** файлы отсортированы по номеру страницы, а номер читается из имени файла

### Requirement: Сохранение одной страницы остаётся доступным

Система SHALL сохранять текущую страницу отдельным файлом по отдельному действию.

#### Scenario: Сохранение текущей страницы

- **WHEN** пользователь сохраняет текущую страницу
- **THEN** скачивается один файл изображения этой страницы

### Requirement: Прогресс и отмена

Во время выгрузки пачки система SHALL показывать прогресс с указанием готовых и общего числа страниц и SHALL позволять отменить операцию.

#### Scenario: Прогресс виден

- **WHEN** идёт выгрузка пачки из нескольких страниц
- **THEN** пользователь видит, сколько страниц готово и сколько всего

#### Scenario: Отмена в процессе

- **WHEN** пользователь отменяет выгрузку в процессе
- **THEN** генерация прекращается, архив не скачивается, приложение остаётся работоспособным

### Requirement: Потоковая обработка страниц

Страницы SHALL обрабатываться по одной: изображение страницы SHALL кодироваться и освобождаться до начала отрисовки следующей. Несжатые изображения всех страниц одновременно в памяти SHALL не удерживаться.

#### Scenario: Длинный текст

- **WHEN** пользователь выгружает пачку из двадцати страниц
- **THEN** выгрузка завершается успешно, вкладка не падает по памяти

### Requirement: Пачка отражает рецепт прогона

Каждая страница пачки SHALL отрисовываться по рецепту текущего прогона: со своим экземпляром листа и с зеркалированием чётных страниц.

#### Scenario: Разные листы в пачке

- **WHEN** выгружена пачка не менее чем из четырёх страниц по семье с несколькими экземплярами
- **THEN** в архиве встречаются изображения на разных экземплярах листа

#### Scenario: Чётные зеркальны

- **WHEN** выгружена пачка
- **THEN** каждая чётная по нумерации страница отрисована зеркально

#### Scenario: Повторный прогон воспроизводится

- **WHEN** пачка выгружается дважды без изменения текста, семьи листов и seed прогона
- **THEN** соответствующие изображения в обоих архивах совпадают попиксельно

### Requirement: Ошибка страницы не теряет пачку

Если отрисовка отдельной страницы завершилась ошибкой, система SHALL сообщить, какая страница не удалась, и SHALL не прерывать выгрузку остальных.

#### Scenario: Одна страница не отрисовалась

- **WHEN** при выгрузке пачки одна страница не отрисовалась
- **THEN** архив содержит остальные страницы
- **AND** пользователь видит номер неудавшейся страницы
