# Стили

1. Новые стили — служебными классами Tailwind. Свой CSS — только там, где классами не выражается; тогда файл лежит
   рядом с компонентом.
2. Никакого `margin` на внешнем элементе. `padding` на внешнем — только если у него есть `border` или
   `background-color`, визуально задающий границы блока. Для отступов используй родительские элементы.
3. Избегай вложенных стилей (каскада) в локальном CSS.
4. BEM — для глобальных стилей.
5. Токены темы объявляются в `@theme` в `src/app/styles/app.css`. Цвета берём из палитры Tailwind, своих не заводим;
   интерфейс тёмный.
6. Порядок свойств в блоке линтером не проверяется — держи его осмысленным: раскладка, размеры, типографика,
   оформление. Пустых строк внутри блока нет (`declaration-empty-line-before` из стандартного конфига).
7. Произвольных значений (`h-[82px]`) избегаем: если подходящего токена нет — спроси, заводить ли новый, или пиши
   обычный CSS.
8. Внешний `className` должен перекрывать дефолт компонента — классы склеиваются через `cx` из `shared/lib/styles`.
